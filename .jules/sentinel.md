## 2026-10-22 - [Fix Tabnabbing Risk]\n**Vulnerability:** A `window.open` call in `shareWhatsApp` (`devo.preview.ts`) was opening a new tab without `noopener,noreferrer` options.\n**Learning:** Opening external links with `target="_blank"` without these attributes can allow the newly opened tab to access the original `window` object via `window.opener`, potentially enabling it to redirect the user to a malicious page (tabnabbing).\n**Prevention:** Always include `noopener,noreferrer` as the `windowFeatures` parameter when calling `window.open` for external URLs with `target="_blank"`.
